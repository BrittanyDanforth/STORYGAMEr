# Particle sprite pack

Generated by `python3 tools/gen_sprites.py`. 21 sprites at 256×256: the 15 the
catalog already uses plus 6 new ones (`heart`, `diamond`, `flame`, `spiral`,
`leaf`, `coin`).

Every sprite is white art over a soft **dark halo**. The halo is there for
Roblox image moderation (bare white-on-alpha particle art has been
false-flagged as empty); in-game every planet emitter runs `LightEmission = 1`
(additive), so the dark pixels add nothing and only the white art glows.

`_sheet.png` is a contact sheet for a quick look.

## Uploading

1. Creator Dashboard → Development Items → **Decals** (or Images) → Upload,
   one PNG at a time. Name them after the file.
2. Wait for moderation, open each asset and copy its **asset id** (the number
   in the URL).
3. In `src/PusherMachine.luau`, find `PusherMachine.SpriteArt` and paste the
   id as `"rbxassetid://<id>"` under the matching key.

The six new keys ship as `"rbxassetid://0"`. Until you paste a real id each one
**falls back** to an existing sprite (heart→petal, diamond→star4,
flame→ember, spiral→smokeWisp, leaf→petal, coin→bokeh), so the new showpiece
planets render correctly either way — pasting the ids just makes them
distinctive.

Re-uploading a sprite that already has an id is optional: only do it if you
prefer this pack's version of that shape.
