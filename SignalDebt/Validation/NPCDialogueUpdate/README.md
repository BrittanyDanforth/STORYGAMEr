The old Editor13/portable173 passes missed the real standalone serializer dependency. The new native key result closes that observed Linux path for the tested source; a compiled Windows player alone does not establish its Windows behavior. Invalid-key feedback is a production status mapping consistent with HTTP401 after accepted input; raw response headers/body were not collected. No real account credential or successful generated dialogue was used in these retained tests.

Recent visible history is limited to 12 prior lines in the UI session, not durable social memory. Jon/Mara profile definitions add no actors, schedules or relationships. Native captures show authored milestone text and setup notices; they cannot validate insult reactions, natural voice or fallible beliefs. Live semantics, broader transport/callback races, Windows runtime, audio and target-hardware performance require separate results.

Native folders contain only their allowlisted reports, masked/empty captures, logs and hash-only fabricated-input/filesystem proofs. No player `Game` folder, `UserData`, key-settings JSON, input value or campaign fixture is retained. JSON/logs were scanned for key-shaped values; selected UI captures were inspected. This bounded check is not a general security certification.
