# Actual Unity PC milestone evidence

These are real Unity 6000.0.62f1 builds and unaltered framebuffer captures from an
uninstrumented standalone Linux game controlled through native X11 input.
They are not Blender previews or screenshots generated from descriptions.

- `native-player-acceptance.json`: sixteen bounded observed checks, exact build
  assembly/source references, save outcomes, logs, 44 capture hashes and limits.
- `player-captures/entry-sequence/05.png`: seated hands at the physical keyboard
  while the same live desktop remains on the laptop screen.
- `player-captures/08-focused-desktop.png`: focused ASTER desktop.
- `player-captures/09-return-first-person.png`: Esc returned to the room.
- `player-captures/16-wallet-paid.png`: actual repair payment and receipt.
- `player-captures/25-restarted-history-4by3.png`: first process restart restored
  the campaign/app state at 4:3, before the final internal-label cleanup.
- `windows-pc-milestone-r2-build-result.json` and
  `linux-pc-milestone-r2-build-result.json`: actual final build results and per-file
  SHA-256 manifests. `pc-milestone-r2-source-manifest.json` identifies their source.
- `windows-r2-user-report.json`: the user's 5 October confirmation that the
  delivered Windows ZIP launches and its laptop/first-person-return flow works.
  This is separately labeled user testimony, not agent-observed Windows output.

The original clickthrough preceded only the History/Rest text cleanup. A separate
r2 addendum and fresh capture record the final UI inspection. Existing Unity
Editor fixture tests were not run: graphical Editor licensing failed. The native
player is the direct runtime evidence. The separate Windows r2 user report does
not establish later-revision behavior, audio, measured performance or full-game
acceptance.

Absolute paths in original reports identify this execution workspace. Companion
reports and captures retained here preserve their relative names; the X11 helper
is retained by the saved cloud setup instructions under `/workspace/SignalDebt-setup`.
