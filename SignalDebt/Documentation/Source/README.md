# Master plan source

The two Markdown inputs and the local Python formatter reproduce the master plan DOCX. The formatter requires Python and `python-docx`; run `python build_document.py` from this directory. It writes `../Hacker_Game_Master_Plan.docx`. The reviewed layout uses Liberation Sans. Export and inspect every changed page again after editing; PDF page counts can vary with fonts and the document renderer. No script here is used by the running game.
